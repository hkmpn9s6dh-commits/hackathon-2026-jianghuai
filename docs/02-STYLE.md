# 02 · 风格与版式预设（闸 A 的第 1–4 节）

## 1. 风格预设

**一句话**：不是"给风景配一段诗"，是**让诗沉到水下**。

| 层 | 定什么 | 为什么 |
| --- | --- | --- |
| 底 | AI 文生图的绢本设色山水（青绿 / 雨灰 / 赭黄三种水色） | 三张各是一条水脉的水色，不靠滤镜统一 |
| 腰 | 一条**朱红水线**，三张同一 y（2245） | 系列唯一的硬骨架；也是"水面"的位置 |
| 下 | **墨池**：水线以下压 72%→96% 的墨，取该图底部中位色 | 让字有地方落，也让"水"真的深下去；不靠加个半透明黑条 |
| 字 | 竖排宋体 92px，右起；单张名用马善政 340px 压左边距 | 竖排是诗的形状；落款压边是碑帖的做法 |
| 印 | 朱红方印，白字，名下一寸 | 三张同一尺寸，代替"署名" |
| 脚 | 三行小字（引文出处 / 地标 / 系列）+ 右下红底白字「AI 生成」 | 赛规要求注明诗句、诗人、地标与 AIGC 标识；合规项做成版面重音 |

## 2. 尺子

**这场是首届（2026-11 才开始征稿），没有往届得奖作可比。** 所以尺子分两部分：

**(a) 能查到的规范（可以逐条对照，不是"感觉"）**

| 尺子 | 学哪一点 | 怎么落到这张上 |
| --- | --- | --- |
| 《人工智能生成合成内容标识办法》(2025-09-01 施行) | 显式标识必须在画面内、可读 | 右下角红底白字「AI 生成」框 + 页脚文字，两处 |
| WCAG 2.1 对比度 4.5:1 | 字压图必须量，不靠眼睛 | `verify.py` AC-27 逐字量真背景，最差 4.8:1 |
| 竖排标点避头尾 | 列首不许出现句读 | 句读不排字，改画成点/圈的记号；AC-15 断言列首无句读 |
| 印刷 300dpi / A4 成品 | 2480×3508 是 A4 的 300dpi 像素数 | AC-2 / AC-3 |

**(b) 同类作品（只作"看什么"的参照，不下图、不混排）**

首届赛没有得奖作可混排，本机也下不到同类海报的高清图（前几场同样卡在这里）。
所以闸 D 改用**同题多版盲排 + 单图盲读**，做法与判据写在 `docs/07-GATE-D.md`，结论按"下限判断"记，不冒充"过了得奖作的线"。

## 3. 一个记忆点

**水线。** 三张同一高度的一条朱线，线上是画、线下是水、字在水里。
看单张是一幅画；看三张并排，那条线是连着的——**这是系列唯一需要被记住的东西**。

## 4. 主屏规格

| 项 | 值 |
| --- | --- |
| 成品 | 2480 × 3508 px（A4 竖版 @300dpi） |
| 安全区 | 左右 ≥120px、上下 ≥40px（AC-18/19 量） |
| 水线 | y = 2245，三张逐像素相同（AC-7/9） |
| 引文 | 92px，列距 149px，列首无句读 |
| 落款 | 340px 马善政，左起 x=172，字头在水线下 140px |
| 印 | 156×156，三张同尺寸（AC-12） |
| 页脚 | 32px 三行，行距 54px，底边 y=3318+108 |
| 交件 | JPEG q95 / 4:4:4 / baseline / 300dpi；同目录附分层 SVG |
