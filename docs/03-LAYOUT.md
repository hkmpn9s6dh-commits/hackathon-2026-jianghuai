## 一套版式为什么这样定

1. **水线**是全系列唯一的硬骨架：三张的水线落在同一行（逐像素），系列才成立。
2. **字号不随图变**：三张共用一个字号（96px），由最长的那一列反解出来；
   改字忘了重算，`verify.py` 的 AC-10 会当场 FAIL。
3. **字全部落在墨池里**：水线以下压一层 52%→95% 的墨，逐字量对比度（AC-27），不靠「看着还行」。
4. **落款压左边距**：名与印贴左，字头在水线下 140px 左右起，与右侧引文形成「一行一柱」的对照。
