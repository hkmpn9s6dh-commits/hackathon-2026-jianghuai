# 07 · 闸 D（第一眼）

## 判据

这场是**首届**（2026-11 才开始征稿），没有往届得奖作可以混排。所以按"下限判断"做，判据只有三条，
全部由**没参与创作的模型**盲读（图注裁掉、只给 A/B/C 三个字母）：

| 判据 | 问什么 |
| --- | --- |
| A 可读 | 只看画面，能不能说出这是哪儿 / 什么主题 |
| B 有事 | 能不能说出这张想让人记住什么 |
| C 无废帧 | 有没有"这一格白放了"的地方；最弱的一处具体指得出 |

三条全中算过线；有任意一条不中，改一轮再测，仍不中就把结果交回用户。
**这不是"排在得奖作之上"的那种过线，别当成一个东西。**

**三条全中 → 过线。** 两位都把 A（丰乐）选为"第一眼最愿意停下来看"，理由一致：暖赭山壁与深绿林木对比最强、纵深最明确。

### 但两位点到的是同一件事，必须改

两条独立作答、用词不同，指的却是同一处：

> 甲：「亭子是题眼，却被前景树叶切碎、半埋进树丛」「舟沉在最暗处，几乎读不出」
> 乙：「应减少亭前枝叶遮挡，让点题建筑完整显出」「应提亮近岸水面并显出渡口或小舟轮廓」

**结论：画的题眼没立起来。** 这不是排版问题，是底图的事——所以改法也不是调字号。

## 第二轮的改法（只改一处）

1. **题眼单独提亮**：在 `story.py` 里给每张一个 `focus=(cx,cy,rx,ry,amt)`，用椭圆形柔和提亮（不改构图、不改色相）。
   - 丰乐亭 (0.39, 0.535)、醉翁亭 (0.50, 0.505)、西涧的舟 (0.24, 0.835)
   - 提亮放在**墨池之后**——舟在水里，得从墨里"捞"出来，而不是先提亮再被压暗
2. **上半微对比**：反锐化掩膜 k=0.25（西涧 0.38），治"雾刷成死灰"。只作用在水线以上，字区一点不动。
3. **水印改中值抹除**：上一版是裁掉源图最下 6%，结果把西涧的船一起裁了。改成对水印框做中值滤波
   ——水印是细白字压在深色水上，中值一过就没了，而那一角在成品里又在 90% 墨池下。

改完重跑 113 条断言（全绿），再把同一组 A/B/C 派回同两位评委（AME-1470 / AME-1472）问两件事：
题眼现在找不找得到、还差哪一处。
