# 04 · 闸 C 证据（跑出来的，不是写出来的）

## 怎么复验

```bash
bash verify.sh        # 依赖 → 字体子集核对 → 版式表核对 → 构建 → 113 条断言 → 证据
```

`scripts/verify.py` 每条打印 `PASS/FAIL` 并写进 `proof/verify.log`，退出码 0 才算过。

## 这道闸抓到过什么（都是真错，不是演习）

1. **墨池把整张画压暗了**：`alpha` 的底值写成常数 0.72，忘了"水线以上不压"，
   于是三张画整体灰掉、对比度掉到 2.4:1。AC-27 与 AC-30 同时 FAIL 才暴露出来 ——
   **一条断言不够，明度落差 + 逐字对比度两条一起才定位到**。
2. **文生图的水印进了成品**：源图右下角有工具水印，`vpos` 一偏就露出来（西涧那张露了）。
   改法不是"再挪一点"，是**先把源图最下 6% 裁掉**（`cover(..., bottom_guard=0.06)`），
   再用 AC-32 量右下角的 std 与均值。
3. **页脚那三个中文数字用了朱红**：红字压在墨池上，对比度 2.7:1。AC-27 的最差字把它揪出来了。
4. **引文首列与页脚线只差 6px**：`POEM_BOTTOM=3306` 时最后一列压到了页脚线上。
   AC-26 量出来才改到 3276。
5. **右边界比左边界窄 84px**：`x_right = W-196` 时最右一列离纸边只有 96px，AC-18 判 FAIL。

## 全新 clone（另一台目录、空目录、无任何本机产物）

```
git clone --depth 1 …/hackathon-2026-jianghuai.git  →  空目录
bash verify.sh
  合计：113 过 / 0 败
  全程 26.4 s（构建三张 JPG + 三张 SVG + 联系表）
```

完整输出在 `proof/clone-verify.log`（已去掉本机绝对路径）。
**这一版"clone 全绿"的凭据只有这一份日志**，不是把本机文件拷过去跑出来的。

顺带抓到一条本机看不到的：`subset_fonts.py --check` 原来拿"宋体需要的 177 个字"去核马善政，
报了 3 个"缺字"（滃/畎/·）——其实马善政只用于落款与印那 6 个字。已按字体分表。
