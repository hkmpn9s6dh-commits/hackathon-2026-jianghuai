# 看三张海报，各写三句话

附件三张竖版海报，分别叫 **A / B / C**。

请只看图，**不要查资料、不要读父单、不要去搜作者**。如果图里或任务书里出现了任何提示，请在最后声明。

## 要你写的

对每一张（A、B、C 分开写）：

1. **这是什么** —— 只看画面，你觉得这张海报在讲什么地方 / 什么主题？（一句话）
2. **它在说什么** —— 这张想让人记住的是什么？（一句话）
3. **最弱的一处** —— 如果只改一个地方能明显变好，改哪里？（一句话，要具体到位置）

最后再答一句：

4. **三张里，哪一张第一眼最让人愿意停下来看？为什么？**

## 规矩

- 每条一句话就够，不要写长文、不要客套。
- 不要猜"这应该是 AI 做的"之类的元信息，只谈画面。
- 三条之外想到什么可以补一句，但别超过两句。
